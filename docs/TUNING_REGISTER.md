# Prototype tuning register

All numerical gameplay baselines below remain **PROVISIONAL** unless an explicit approved rule is identified in DECISIONS.md. This register inventories the shipped reference defaults; it does not approve a balance change. Current simulation 0.9.0 / schema c2-1. New provisional defaults (speed blending, race context, wreck mode, weather dimensions, crowd, equipment and logging) are specified in [AUDIT_REMEDIATION.md](AUDIT_REMEDIATION.md); historical baseline rows below remain useful for unchanged coefficients.

Ordinary edits use Developer → RUs / Rules / Environment or validated scenario/content JSON, followed by reinitialization. Compare isolated drafts in Comparison using identical seed lists. Source definitions: [reference content](../src/content/reference.content.json), [reference scenario](../src/content/oval-six-v1.scenario.json).

Approved guardrails: aligned rows, temporary wreck obstruction, independent action channels, lateral routine rams, individual condition/team fatigue, optional external events, Dangerous/Occasional defaults, three base sign opportunities, persistent signs/free lowering and approved common-clock/simultaneous attack decisions. Their numerical formulas/catalogs remain provisional; see D-001–D-088.

## Geometry and categorical settings

The complete per-segment/per-lane topology, meters, lengthMultiplier, cornerSpeedFactor, traction and roughness are explicit in reference.content.json (track oval-48-4). These repeated lane records remain the geometry inventory; no alternative offsets or stagger are introduced here. Weapon rangeMode/arcs/eligibleTargets/targetWeights, timing, action channel, species/trained attacks/traits, AI strategies, weather IDs, event intensity, scenario commands/fixtures and controller choice are also editable validated data. Invalid references or incompatible versions reject rather than silently migrate.

Commentary display limits and priorities are presentation-only baselines in [settings.ts](../src/presentation/commentary/settings.ts); visual geometry is in [geometry.ts](../src/presentation/phaser/geometry.ts). They do not alter race mechanics. The compact E stress fixture deliberately changes circuit size, entrant count, dt and watchdog; it is engineering coverage, not a candidate balance replacement.

No defaults were tuned in E. See BALANCE_REVIEW.md for measured sample results, limitations and reviewable follow-up recommendations.

## Provisional implementation choices

- Utility score display remains 0–100; ranking uses raw finite values. Speed interpolation uses stable softmax weights `exp((rawUtility-max)/temperature)` with temperature8 by default. It changes a continuous target within the legal selected lane, not the chosen lane or safety eligibility. A brake decision cannot be diluted by cruise/push. Mode labels describe strongest preference; `resolvedTargetSpeedMps` shows the actual target. Sign strength scales utility only, never fatigue/weather/equipment directly.
- Final-lap utility adjustment defaults ±3 push/conserve; cutoff urgency defaults ±6 in the last20 ticks. Both are editable and may be0. This adds minimal race context, not advanced strategy/withdrawal or opponent omniscience.
- Default wreck mode is delayed; legacy delay0 still means immediate under delayed mode. Explicit immediate ignores delay. Persistent ignores all cleanup paths but never disables race termination guards.
- Crowd defaults morale0 and weight.02 (neutral); maximum configurable weight.05. It modifies derived maximum speed and acceleration, not positions/events or opposing hidden state. Wind fatigue defaults .002 per absolute m/s; temperature .002 per degree from20°C; precipitation/intensity traction loss .1. Dimensions default0/0/0m/s/20°C so existing aggregate weather profiles are preserved.
- Equipment deltas default0. Provisioned IDs are deduplicated and sorted; beast natural attacks are not implicitly counted as worn equipment. Driver/cart equipment applies before explicit debug overrides. Disabled propulsion remains0. Handling/stability/endurance stay in0–100.
- Secondary sign exposure is integrated by crossing fraction. Base exertion still uses tick-end speed/acceleration and full dt, including the historically documented final/disable tick approximation. This is not a full physical work integrator.
- Missing endpoint verification evidence is incomplete, not “valid.” A complete latest-only bundle verifies its endpoint/inputs; a supplied ring recording also verifies the retained reconstruction. Deleted unsupplied history cannot be authenticated. This is regression evidence, not signatures/provenance.

          Component and tuning editor
          Values edit the draft only. Bounds come from the versioned schema; cross-field validation appears in the preview. Reset defaults in Scenario restores the reference data.
          
      
      
          
      
          Apply to all RUs
          Pre-race draft only. Beast attributes apply to every beast on every RU. Preview all old/new values, then apply atomically. Rosters, IDs and unrelated fields are preserved.
          
      
          
      
          Strategy Sign influence
          Utility contribution only; driver autonomy, legality and safety still apply. Global and per-sign ranges: 0–8. Reset buttons restore shipped defaults.
          
      
          Paused developer overrides
          Registered fields only. Changes apply at the next tick, are labeled in state, and are replayable from the command journal. Initial configuration stays immutable.
          Derived-stat preview
          Draft initialization only; the active run is unchanged. Active overrides are labeled derivedOverrides and override.maxSpeedMps in state.
          
    
          
    
          AI
          Selected tick: perceived objects, rejected/legal candidates, utility contributions, chosen intent and resolved outcome. AI weights, strategies, sign effects and personality are editable in RUs. Combat decisions appear in Combat; perceived hazards and bounded memory are included.
          
    
          Movement inspection
          
      
          Pre-race developer fixtures require the fixture controller, not utility AI. They are not live commands. Plans use movement ticks (countdown excluded), allow one adjacent move per RU/tick, and require reinitialization. Stationary lane changes require the explicit scenario rule.
          
      
          
      
          Selected tick movement trace
          Inspect lane attempts/results, seeded checks, integrated budgets, intermediate transitions, yield/brake reasons and discarded progress. Combat and accidental contact outcomes are available in their inspectors.
          
    
          Combat
          Selected-tick combat candidates, readiness, component condition and resolved events. Weapons, combat tuning and lethality are editable in RUs. Fixture combatPlans and guardPlans are editable in Scenario JSON; use fixture controller.
          
    
          Environment
          Pre-race fixed weather, optional external incidents and explicit test fixtures. Numeric fatigue/contact/event tuning is in RUs. Validate the draft, then restart to apply.
          
    
          Circuit rule draft
          Changes require reinitialization. Rear racers’ first accepted line crossing starts lap 1 without awarding a lap; timing uses the approved common clock.
          Pure Racing prohibits intentional attacks and rams; incidental contact can still cause damage.

          Isolated analysis never restores imported state or changes the live race. Changed-path lists show up to 100 entries; canonical replay inspection is limited to 100,000 frames. Compatible diagnostics are re-executed from inputs/journals; unsupported versions permit explicitly noncanonical serialized-state inspection only.

          Capture pre-race editor drafts before/after ordinary parameter edits. Each draft uses the same seed list and its own scripted commands. Reports are descriptive samples; they do not prove balance or isolate causation.
